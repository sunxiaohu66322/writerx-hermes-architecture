## 0. 结论摘要（六行）

1. **同一引擎、两个 profile**：WriterX = **3 个 bundle**（`dsh-base` + `dsh-web-app` + `@writerx/dsh-hermes-app`）；Lead 的 DSH desktop = **43 个 bundle**。差的全在"本地插件层"与"宿主工具层"。`[事实]`
2. **付费墙有三种来源，别混**：① 本地真判定（`@writerx/dsh-entitlements` 的 8 个 feature）；② **服务端返回**（"会员专享"文案在本地 77 万+ 行 JS 里 **0 命中**）；③ **结构性缺失**（`web_fetch` 在补丁里写明 absent）。`[事实]`
3. `custom_model_channel` 有三处硬调用点（`index.js:91/97/108`），另有 HTTP 授权口（`:706`）——这是"自己的 API 被拦"的真源。`[事实]`
4. `decompose` / `style_distill` / `heavy_import` / `generation` 的闸门**在前端 bundle 与产品 UI** 里调，不是引擎工具层。`[事实]`
5. `workflow` / `ralph` / `subagent-fork` **只在「写作助手」预设里禁用**；「创造模式」预设三个都开着 → 不是"全面封禁"。`[事实]`
6. `内部组件\skills\axu-novel\references\存档.md` **盘上不存在**：`内部组件` 全盘 0 命中、axu-novel 只有 `references\档案.md`；两棵 skills 树里提「存档」的只有 brain-bridge（目录名）与 thunder-download（下载脚本位置）。**判定为模型编造的路径**。`[事实]`+`[推断]`
