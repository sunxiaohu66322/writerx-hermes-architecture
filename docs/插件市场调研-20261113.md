### 三档结论

- **直接能用（低侵入、不改模型/预设/系统提示词）**：`[事实]` 26 条（表 A 行数，含组合装的行）—— 官方记忆检索 / 省 token / 提醒 / 文件引用 / 会话回退 / 任务看板类，本机已有或 npm 可装。这类是本次最该先装的。

- **没有现成的**：`[推断]` ① 本机可离线读取的插件市场索引；② `@local/*` 私有 scope 的 npm 公开分发（全部只能本机目录复制）；③ 把「开书→拆解→设定/大纲→分章取证→只报错不改稿→候选稿采用→进度灯」做成单个 DSH bundle 的成品。
- **合计候选 31 条（26 + 5）**。

### 最值得先装的 3 个（按「低风险 + 当天出活」排序）

1. **`dsh-at-file`**（npm 0.6.3）—— `@` 引用设定稿/章节文件，明确不注入内容、不碰模型链路，装一个就解决「分章取证时贴全文」的烧钱动作。
2. **`dsh-checkpoint-rewind`**（npm 0.6.34，桌面版已在用 0.6.33）—— 改稿试错能退回「候选稿采用」那一步，直接对应 WriterX 的候选稿流程。
3. **`@deepseek-ai/dsh-experimental-session-search`**（本机 0.2.1-rc.3 已在缓存）—— 与主人已点名的 `graph-memory` 形成双层：胶囊查摘要、本件查原始会话全文。

`[推断]` 若愿意投入隔离验证，**`dsh-novel-writer` 7.3.2** 是与「设定检索 + 只报错不改稿 + 文风量化」契合度最高的写作专用成品，但它带 22 工具与侧栏 UI，优先级排在上述三个之后。
