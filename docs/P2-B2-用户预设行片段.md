## ② 那一行里要改哪几个键

假设你复制「写作助手」并命名 id 为 `assistant-web`（推荐用**新 id**，别复用 `writerx-assistant` —— 内置行受保护，
`index.js:29-36` 的 `PROTECTED_ROW_IDS` 会拒绝删除，且产品升级会覆盖内置声明）。

### 2.1 开 `web_fetch`：把 `fetch: false` 改成 `true`

在你刚复制出来的那一行内部（缩进按实际层级对齐）：

```yaml
        plugins:
          # …前面几十行原样不动…
              - id: tool-web
                name: '@deepseek-ai/dsh-tool-web'
                config:
                  fetch: true          # ← 由 false 改为 true
                  searchMaxQueries: 1
                  searchMaxResults: 8
                  searchTimeoutMs: 60000
          # …后面原样不动…
```

**依据**：
- 写作助手预设里这一行是 `fetch: false`（`presets/writerx-assistant.patch.yml:344-350`），创造模式同样（`create.patch.yml:230-236`）。
- `fetch: true` 是引擎自带的合法值：base 就是 `fetch: true`（`dsh-base:486-490`）。
- 抓页 provider 我已经在 profile 顶层钉死成 `http`（`P2-能力补齐落地.md` §1），
  对应 `@deepseek-ai/dsh-web-fetch-http/lib/index.js:422` `LOCAL_FETCH_PROVIDER_ID = "http"`；
  该包行由 `dsh-base:483-484` 挂载，全树无 `disabled` 命中。
- ⚠ **不要**同时去顶层再开宿主 `tool-web`：宿主行被 `dsh-web-app:555-556` 显式 disabled，
  而 `dsh-web-app:461-463` 注释说明禁用就是为了避免与预设行重复注册。

### 2.2 开 `workflow` / `ralph`：删掉 `disabled: true`（或改 `false`）

同一行内部：

```yaml
              - id: tool-workflow
                name: '@deepseek-ai/dsh-tool-workflow'
                # disabled: true        ← 删掉这一行（或写 disabled: false）

              - id: tool-ralph
                name: '@deepseek-ai/dsh-tool-ralph'
                # disabled: true        ← 删掉这一行
                config:
                  subagentProvider: spawn
                  maxRounds: 64
```

**依据**：写作助手里这两行是 disabled（`writerx-assistant.patch.yml:319-325`），创造模式里是全开
（`create.patch.yml:204-216`，`tool-ralph` 带 `maxRounds: 64`）。
`disabled` 接受布尔或 `!!js` 表达式（loader schema 原文："Boolean or !!js expression. The Loader coerces other truthy values as disabled"），
所以 `disabled: false` 也合法；**推荐整行删掉**，少一层歧义。

**影响面（改之前请确认你接受）**：
- `tool-ralph` = 自我迭代循环（`maxRounds: 64`）；一个指令可能触发多轮自动改写。
- `tool-workflow` = 把多步编排成脚本跑；会连开子代理。
- 写作助手原本的设计前提是"单章可控、每章交你采用"（`writerx-assistant.patch.yml:27` 注释：
  "主助手…禁用通用 workflow/Ralph 和历史 fork"）。打开后**成本、时序、"到底哪一版被采用"都会变难追溯**。
- 想用这些能力时，**更省事的做法是直接切「创造模式」**（那边全开），而不是改写作助手。

### 2.3 不推荐改的两个键

| 键 | 为什么别动 |
|:--|:--|
| `searchMaxQueries` / `searchMaxResults` | 与 Hub 的 tool-call / 次数幂等一一对应（`create:228-229` 注释），放大后可能被服务端拒或重复计费 |
| 预设里的 `workflow-ptc` / `subagent*` 行 | 它们本来就开着（`create:204-207`、`assistant:314-317`），无需改 |
