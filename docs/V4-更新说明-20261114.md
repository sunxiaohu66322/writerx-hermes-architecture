## 1. 主人要什么（一句话）

作者另有一套生图系统，WriterX 里的「AI 配图」（对接深图云端模型 / 生图余额 / 按张扣费 / 购买生图包）**完全不需要了**。
改成**本地图片资料包管理器**：登记本机任意图片文件夹为「资料包」→ 面板里看得见每包存录了哪些图纸 →
选单张或整包 → 放进书里当封面 / 人物立绘 / 场景插图 → **图片包插进正文后轮番展示（轮播）**。

## 3. 数据流 / 接口（A↔B↔C 三方同构，已独立复核）

```
登记   书目录\<书>\图片包\资料包.json  = {packs:[{id,name,root,note,updatedAt}]}   root=本机任意绝对路径
读包   GET  /novel-shelf/image-packs?dir=        → {packs}（B L4152；坏/缺→{packs:[]}）
写包   POST /novel-shelf/image-packs?dir=  {packs} → 只写书目录内（safeTarget+writeAtomic）
列图   GET  /novel-shelf/local-images?root=&sub= → {entries:[{name,kind,ext,path}],total}（B 早分派 L3639，不带 dir）
读图   GET  /novel-shelf/local-image?root=&path= → 原始字节 + nosniff（B 早分派，不带 dir）
落书   POST /novel-shelf/cover|portrait|illustration?dir= （沿用既有逻辑，illustration 新增可选 frames + 40MB body 闸）
```

**frames 三方同构（轮播关键）**：
```
A 请求  frames = [{data(base64 jpeg), width, height}, ...]        （主图=ordered[0]，其余=ordered.slice(1)）
B 索引  frames = [{id, version, width, height}, ...]              （每帧另存 <frameId>.jpg，走 updateIndex stage 原子落书）
C 渲染  item.frames[].{id,version} → illustrationUrl(dir,id,version)（seq=[主图,...frames]，setInterval 3500ms 循环切）
完整序列 = [主图, ...frames]，frames 只存「除主图外的附加帧」；单张不写 frames、完全兼容老数据。
B.readIllustration 能按 frame.id 命中返回该帧 jpg + version  →  轮播第 2 帧不 404（最大风险点，已闭合）。
```

B 护栏 7 条：root 绝对路径+realpath+目录 stat（不存在 404）· 禁 `..`/绝对路径/盘符 + realpath 防软链逃逸 400 ·
6 扩展名白名单 · 单图≤8MB→413 · 单目录≤500 · POST 只写书内 · 全部过 `assertTrustedRequest`。

C 清理：轮播 timer 挂 `node.stopTicking` → illustration widget 补 `destroy:stopTicking` → widget key 加 frames 指纹，
frames 变化时重建 DOM、旧 interval 随 destroy 清掉、不叠加；单张图整块跳过，行为与改前一致。
