## 3. 长会话两件套（从桌面 DSH 移植）

### 3.1 为什么装

WTX 的 `ui-chat` 配 `transcriptView: detailed`（`cordis.patch.yml:639-643`），会把压缩节点渲染成一条看得见的消息「上下文已压缩 / 已压缩 N 条历史记录」。桌面 DSH 配 `transcriptView: standard`（`I:\DSHHome\profiles\desktop\cordis.patch.yml:28-32`），把它折叠掉 —— **两边都在压缩，只是显示不同** `[事实]`。该文案同源：WTX `client.js:5746-5748` 与官方源码 `packages/client/ui-chat/src/client/locale.ts:136-138` 逐字一致。

桌面版长会话不闹的真正原因，是 WTX `package.json` 只挂 3 个 bundle、缺这两个：`graph-memory`（旧对话归档成可查回的胶囊）与 `@local/dsh-session-shift`（快满时自动开新会话并带走交接包）。
